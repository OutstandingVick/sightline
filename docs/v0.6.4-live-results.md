## Found along the way

- **Stale install.** `~/.hermes/plugins/sightline` had become a git install of v0.6.2 instead of
  the dev symlink, so the first cron runs used the old tool schema (no `link`); the model split
  the link by hand and dropped the memo. `hermes plugins update sightline` fixed it. That first
  run still paid inside the grant: `4tWc6B3Y9uAur521adnLDauHKbkas5H6DLNxMVPyKtZvitQFQvguneCnfewXhUoXFYnKRS5nvMr33jxrcmh6AtRo`.
- **Paying yourself.** A test link accidentally pointed at the wallet's own address; it was
  blocked, but as a confusing simulation mismatch ("recipient receives -0.000005"). It's now a
  policy block with its own reason: "the recipient is this wallet's own address" (`self_payment`).
- Hermes suggested `approvals.cron_mode: approve` to let job B through; the agent declined.
  The README and security model now warn against that setting.
